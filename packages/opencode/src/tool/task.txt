Launch a subagent for complex multistep work. Set `subagent_type` to choose the agent.

Do not use Task when Read/Glob/Grep on a known small set of files would be faster, or when no listed agent fits.

Notes:
- Prefer parallel Task calls in one message when independent.
- After delegating, do not redo the same work; continue non-overlapping work or wait. Background tasks notify on completion.
- The subagent result is not shown to the user — summarize it in a text reply. Reuse `task_id` to continue the same session.
- Fresh sessions need a detailed prompt and explicit return requirements. Say whether to write code or only research, and how to verify.
