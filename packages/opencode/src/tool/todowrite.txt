Maintain a structured task list for the session.

Use when work has 3+ distinct steps, multiple user tasks, or needs planning. Skip single trivial edits, pure Q&A, or when tracking adds no value.

States: `pending` | `in_progress` (exactly one while work remains) | `completed` | `cancelled`.

Rules:
- Update live; mark `completed` only after required work (and verification) is done.
- If blocked, keep `in_progress` and add a follow-up for the blocker.
- Keep items specific/actionable; preserve user commands verbatim.
