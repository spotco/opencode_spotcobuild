Exact string replacement in files.

- Read the file at least once before editing.
- Match content after the Read line-number prefix (`N: `); never include that prefix in oldString/newString. Preserve indentation.
- Prefer editing existing files over creating new ones. No emojis unless asked.
- Fails if oldString missing or not unique — add context or use `replaceAll`.
- Use `replaceAll` to rename/replace every occurrence in the file.
