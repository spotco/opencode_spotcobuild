Read a file or directory (absolute path). Missing path → error.

- Default: up to 2000 lines from the start. `offset` is 1-indexed; reread with a larger offset for later sections.
- Prefer Grep for needles in large/long-line files; Glob if the path is unknown.
- Lines are `N: content`. Directories: one entry per line, `/` suffix for subdirs. Lines >2000 chars truncated.
- Parallelize known multi-file reads. Avoid tiny repeated slices — use a larger window.
- Images/PDFs return as attachments.
